# 微信小程序上架清单（点位速查）

> 配合 OpenSpec change `add-lineup-quick-lookup` 任务 6.2。注册与提审为人工操作，本文只列要点。

## 注册

- [ ] 注册主体：个人主体即可（mp.weixin.qq.com → 小程序注册），需身份证 + 手机号。
- [ ] **类目选「工具 > 信息查询」**，个人主体可用、无资质要求。
  - ⚠️ 千万不要选「游戏」类目（需要游戏版号），本产品定位是第三方攻略查询工具。
- [ ] 名称建议含「点位」关键词便于搜索（如「瓦点位速查」），**不要包含**「无畏契约」「Valorant」「VALORANT」官方商标全称，简介中可表述为「适用于某战术射击游戏的玩家攻略工具」。
- [ ] 头像/Logo 自行设计，不得使用官方 Logo、官方美术素材。

## 开发配置

- [ ] AppID 拿到后替换 `apps/lineup/project.config.json` 的 `"appid": "touristappid"`。
- [ ] 服务器域名白名单（小程序后台 → 开发管理 → 开发设置）：
  - downloadFile 合法域名：图片 CDN 域名（腾讯云 COS/CDN，需 HTTPS）。
  - 当前无 request 接口依赖（内容打包在代码内）。
- [ ] 代码包体积：主包 ≤2MB。内容 JSON 与代码同包，图片全部走 CDN，注意随内容增长监控 `dist/weapp` 体积（必要时内容 JSON 改为分包或远程拉取——已有 schema 不变）。

## 隐私与合规

- [ ] 用户隐私保护指引（后台必填）：本程序不收集个人信息；收藏/最近查询仅存于设备本地 storage。
- [ ] 游戏截图素材：自行游戏内截图 + 自制标注，属攻略工具行业惯例；避免成片搬运他人视频/图文。

## 提审

- [ ] 提审备注写明：「第三方玩家攻略查询工具，内容为自制游戏截图与文字攻略，不含游戏运营功能、无充值、无社交」。
- [ ] 准备 2-3 张功能截图（首页/清单/详情）。
- [ ] 常见驳回应对：若被认定游戏类目 → 申诉强调「攻略信息查询工具，无游戏内容本体」；若名称侵权 → 改名去掉商标词。
