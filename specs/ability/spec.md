## 关于技能的说明


valorant这个游戏当中不同特工可以释放不同的技能， 这些技能可以抽象为几种类型（某些技能可以具备多个类型）:  烟雾，位移，伤害，闪光，震荡, 护盾，治疗，建造 等等，暂时不全，后续我会补充。

关于技能的属性可以在 src/features/abilities/config.ts 中进行迭代配置 


### 烟雾

效果为遮蔽视野，通常为球形烟雾和线性烟雾。 球型烟雾在小地图中显示为圆形，线性烟雾显示为直线/曲线。


#### 球型烟雾设计

圆形，背景色为纯色：#616462， 边缘光晕根据攻防两方颜色不同，分别显示为蓝色和红色。


交互：src/features/map/components/AbilityInstanceActionPopover.tsx 中点击激活后，如果技能类型为球型烟雾，则先把这个烟雾渲染出来并加入半透明效果，然后圆心吸附在鼠标上，等待用户点击确认施放的位置。 用户点击ESC按钮取消施放， 用户点击鼠标左键后将烟雾释放到鼠标点击的位置。
实现: 使用 Konva + React 实现, 在 map 组件中进行渲染。


##### 与时间轴的关系

1. 每个球型烟雾都有 开始时间 和 结束时间， 开始时间在技能放置后立即开始，存续时间根据不同技能有些许不同，比如jett的瞬云只有2.5秒，而clove的霞染有14秒。
2. 每个球型烟雾确定施放的时候，需要在在时间轴上生成一个关键帧（如果当前时间没有关键帧），并且在关键帧的 “技能施放” 栏目新增一个项目，代表本次技能的施放。
3. 每个球型烟雾在消散的时候（到达结束时间），也需要在在时间轴上生成一个关键帧（如果当前时间没有关键帧），并且在关键帧的 “技能施放” 栏目新增一个项目，代表本次技能的结束。

##### 关键帧
1. 在关键帧的detail drawer中需要新增"技能施放“ 的栏目
2. 栏目中需要展示本次施放的 技能名称， 技能施放者 （用AgentMapTokenChip 展示），技能状态（开始/结束） 并在最右边有一个 “删除” 的icon按钮，点击后可以删除这个技能。


##### 操作popover
使用组合件 command + click 点击地图上的技能实例，会弹出操作popover， 第一个按钮是 "施放时间", 第二个按钮是 “结束时间", 第三个按钮是 “删除”

1. “施放时间” 按钮： 自动回到时间轴的 该技能施放时间对应时间点
2. “结束时间” 按钮： 自动回到时间轴的 该技能结束时间对应时间点
3. “删除” 按钮： 删除该技能实例




#### 线型烟雾设计

线型烟雾比球型烟雾复杂，所以我把它们细分开来：

1. 笔直线烟 - 双线（霓虹高速通道）
两条等长平行直线，长度与间距固定。点击激活后中点吸附鼠标，朝向随鼠标相对施放者变化，左键确认，Esc 取消。

2. 笔直线烟 - 单线（蝰蛇毒幕）
单条固定长度直线，交互与霓虹相同（中点跟鼠标、朝向随鼠标），仅少一条平行线。长度见 `smoke.md` `length_meters`。

3. 弯曲线烟（不死鸟火墙、海神 High Tide）
按住左键拖动画曲线，松手确认；折线路径总长度不超过 `smoke.md` 的 `length_meters`（地图坐标由 `smokeLineLength` 换算）。路径过短作废。Konva 使用带 `tension` 的平滑折线。

颜色： 各技能在 `ABILITY_EFFECT_META` 的 `smokeLineColor` / `smokeLineStrokeWidth` 中配置。

##### 与时间轴的关系

与球型烟雾相同：确认施放时记录开始时间并写入关键帧「技能施放」；到达 `smokeDurationSec` 时记录结束时间并再次写入关键帧。

##### 操作 popover

与球型烟雾相同：⌘/Ctrl+点击已施放线烟可打开操作 popover（施放时间 / 结束时间 / 删除）。

#### 笼状球型烟（Cypher 战术网络）

交互与球型烟雾相同；视觉上为空心圆柱笼（虚线外圈、半透明填充），半径与时长见 `smoke.md`。




### 位移

位移技能通常是特工从当前位置瞬移到某个位置，每个特工的位移功能细节都有所不同，但大致可以分为以下几种类型：

1. A到B的直线位移 （直接）
代表特工: 捷风 - 逐风, 幻棱 - 光速飞跃, 霓虹 - 充能疾驰（滑铲）, 幽影 - 暗影潜行 （特殊：施放技能后有一些时间的延迟，之后才瞬移到目标位置，设计上预留这个时间差, 因为幽影特殊性，所以默认值为0， 幽影可以预设一个0.5秒）
顾名思义就是直接施放技能之后就瞬移到目标位置。

交互：点击技能后先放置一个预备期技能 token；⌘/Ctrl + 点击该 token 后点击「激活」进入目标点选择。目标点以施放者当前位置为起点，并按该技能 `range_m` 换算出的地图距离上限裁剪。左键确认后，施放者立即移动到目标点，并在当前关键帧记录一次「瞬发」技能施放。

显示：直线位移轨迹只在该次位移发生的关键帧上显示。播放头离开这个关键帧后自动隐藏轨迹，避免地图长期堆积过多位移线。施放后的特工位置仍随时间轴快照保留。

2.  A到B的直线位移 （依赖技能的提前释放）

- 幻棱 - 溯流回光：依赖提前点击E键放置一个（静止）光标，再次点击E键之后瞬移到光标位置。
    - 第一次触发：⌘/Ctrl + 点击特工头像打开技能 popover，点击「溯流回光」后，系统自动在特工当前位置放置一个溯流回光标签，表示稍后要回到的位置。
    - 第二次触发：再次 ⌘/Ctrl + 点击该特工头像打开技能 popover，此时「溯流回光」按钮需要有明显的可再次触发状态（当前实现为金色发光态）。点击后特工瞬移回第一次留下的标签位置，并在当前关键帧记录一次「瞬发」技能施放。
- 夜露 - 不请自来：这个技能是难点，依赖提前点击E键放置一个移动光标，这个光标会向一开始施放技能的方向一直移动，这里可能需要一些物理引擎的计算（可以优先使用优秀的第三方库）
    - 夜露的光标详细描述
        - 飞行速度：800 uu/s（单位 / 秒，瓦罗兰特内部距离单位）
        - 移动模式：水平地面吸附（只在地面 / 斜坡滑行，不会跳 / 飞高）
        - 光标 = 控制发射方向；锚点一旦飞出，方向不再受光标控制。
        - 碰撞层：仅与 “垂直墙面 / 固体障碍物” 交互；可穿过玩家、子弹、大部分技能（目前可以先不考虑特殊情况，可穿过全部技能）
            - 撞墙（垂直固体）
            分两种情况：
            A. 斜角撞墙（θ ≠ 90°，最常见）
            接触瞬间：速度保留，但施加 “摩擦减速”
            摩擦系数 ∝ 与墙面夹角：越接近垂直，摩擦越大
            表现：沿着墙面滑行，速度逐渐降低，直到能脱离墙面继续直线或完全停下
            B. 垂直撞墙（θ = 90°，正对着墙射）
            摩擦最大 → 瞬间几乎停住
            结果：直接卡在墙前，不再移动

        - 停止条件（满足其一即停）
            贴墙摩擦 → 速度降到 <50 uu/s → 强制静止
            锚点寿命 30s 到 → 消失
            被敌人打掉（60 血）→ 消失
            掉出地图边界 → 消失
    - 夜露的这个光标的系统的移动UI以后还可以被其他技能复用，例如 斯凯的鸟和狗， 盖可的皮蛋和鲨鲨在小地图上也需要显示一个移动的光标（现在暂时不用实现， 但是光标的系统的移动 模块需要做成可复用）
	- 尚博乐 - 闪转自如： 依赖提前点击E键放置一个（静止）光标，再次点击E键之后瞬移到光标位置。
    - 第一次触发：⌘/Ctrl + 点击特工头像打开技能 popover，点击「闪转自如」后，地图进入锚点放置模式。以当前特工为圆心显示一个可放置半径，鼠标移动时锚点预览吸附在半径范围内，左键确认后放置锚点。
    - 第二次触发：再次 ⌘/Ctrl + 点击该特工头像打开技能 popover，此时「闪转自如」按钮需要进入可再次触发状态。点击后特工瞬移回锚点位置，并在当前关键帧记录一次「瞬发」技能施放。
- 雷兹 - 惊喜翻腾： 依赖提前点击Q键放置一个（静止） 光标（炸药包），第二次触发需要通过 ⌘/Ctrl + 点击雷兹头像打开技能 popover，再点击高亮的 Q 技能引爆炸药包，通过爆炸产生的余波进行位移。
    - 第一次触发：⌘/Ctrl + 点击雷兹头像打开技能 popover，点击「惊喜翻腾」后直接进入炸药包放置模式。以当前雷兹为圆心显示可放置半径，左键确认炸药包位置；不通过地图上的炸药包 token 触发。
    - 第二次触发：再次 ⌘/Ctrl + 点击雷兹头像打开技能 popover，此时「惊喜翻腾」按钮进入可再次触发状态。点击后引爆炸药包，按炸药包到雷兹的方向计算击退位移，并在当前关键帧记录一次「瞬发」技能施放。伤害和更精确的内外圈衰减可后续接入。
    - 炸药包的详细描述
        1. 爆炸半径（伤害 + 击飞 / 位移范围）
        内圈（满伤）：1 m（100 uu）
        外圈（有伤害 + 有击飞）：5 m（500 uu）
        余波 / 弱推动范围：约 5–6 m（只有轻微击退，无伤害）
        2. 伤害分布（必须完全部署 = 落地 0.5s 后）
        0–1 m：50 伤害（满伤）
        1–5 m：线性衰减 → 20 伤害
        >5 m：0 伤害，仅微弱推力
        立刻引爆（没等 0.5s）：5–15 伤害，范围相同
        3. 击飞 / 位移范围（和伤害范围一致）
        0–5 m：强击退（可以用来跳、拉人）
        5–6 m：弱击退（几乎不影响走位）
        >6 m：无位移
        4. 炸药包本身
        血量：20 HP
        持续时间：5 s（超时自动爆）
        可被射击引爆（伤害按当前状态）
    惊喜翻腾这个技能可以抽象为： 有技能伤害，有推动位移效果，依赖先施放后引爆的技能。（以后做的部分技能会有相似特性，以后再说）




#### 位移技能设计

位移技能通常用于快速移动到某个位置，或者快速逃离某个位置。

#### 位移技能与时间轴的关系

位移技能是瞬发的，在时间轴上只有一个关键帧， 关键帧的detail drawer 里的具体交互和烟雾技能相同。
